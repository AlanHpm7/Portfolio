4WRP: object tracking robot platform

Engineering Projects IV & V / Winter to Fall 2024 / with Matthew Gajewski on Project V
The finished platform. Custom PCB, ultrasonic sensing, and a pan-tilt camera mount.

4WRP (4-Wheel Remote Patrol) spans two course terms. In Project IV, I designed the custom hardware around an STM32 Nucleo controller: two separate PCBs, a pan-tilt camera mount, and CAN and RS-232 communication interfaces. In Project V, we built on that hardware to add real-time object tracking and collision avoidance, working around an older chassis and its aging wiring along the way.

4WRP: custom PCBs, from schematic to bring-up (Project IV)

Designed two boards in Altium around an STM32 Nucleo controller, one for power and battery input, one for the control electronics, then debugged legacy C and Assembly motor driver code so it would run on the new hardware.

  • Designed separate power and control PCBs for the robot platform in Altium, built around an STM32 Nucleo-64 board
  • Built a pan-tilt camera mount driven by a stepper motor and an RC servo, with CAN bus and RS-232 as the external communication interfaces
  • Added a keypad and LCD for local control and status, alongside an ultrasonic sensor for distance sensing
  • Adapted low-level motor driver and encoder code across the hardware revision, then brought the boards up through continuity testing and direct signal validation

Real-time obstacle avoidance (Project V)

Ultrasonic sensing and a tuned PD control loop for smooth, responsive collision avoidance, built on top of the Project IV hardware.

  • Integrated ultrasonic sensors for real-time distance measurement
  • Tuned PD control gains to reduce overshoot and improve motion stability
  • Built wireless UART command execution for remote control
Connector/IO board: CAN, keypad, LCD, and encoder headers.
